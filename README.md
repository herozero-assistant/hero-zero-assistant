# BoltMind

Public site: https://herozero-assistant.github.io/hero-zero-assistant/

Static product site for Hero Zero automation. Real program screenshots in Portuguese, English, Polish and Greek; German and French use English screenshots. All six site languages have their own copy.

Lifetime base price: BRL 147, verified at checkout on 2026-09-25. pricing.json contains dated estimated FX rates; these are informational, not guaranteed checkout prices. Refresh this file when rates or base pricing change.

Support is Discord and email. Login and tickets are intentionally deferred at the user's request. No credentials or private customer data are collected by the site.

Previous design is preserved in Git history and branch backup/boltmind-before-real-product.
